# DroneOptAI Technician - TanStack Query conversion

Copy the `technician` folder into:

```text
src/features/technician
```

Then install:

```bash
npm install @tanstack/react-query
```

Configure `.env` from `.env.example`, restart Vite, then run:

```bash
npm run dev
```

When Operator TypeScript errors are fixed by the Operator developer, validate the full project with:

```bash
npm run build
```

More detail: `technician/TANSTACK_QUERY_SETUP.md`.
